# Pawfolio — instructions for AI assistants

Pawfolio is a LinkedIn-style adoption platform (school project). Before doing any development work in this repository,
follow the project rules below. They are the single source of truth for conventions; if a new project-wide rule is agreed,
update the matching file in `project-rules/` instead of relying on it being repeated in prompts.

Security: `project-rules/security-guidelines.md` is the authoritative security standard, based on and cross-referenced with the
Senior Security skill (`.claude/skills/senior-security/`). Apply it to all work and complete its §10.1 checklist for every new
feature or module.
